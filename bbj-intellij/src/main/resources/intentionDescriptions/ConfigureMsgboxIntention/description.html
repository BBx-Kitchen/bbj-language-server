Opens the BBj visual composer for the MSGBOX(...) call under the caret.

The composer is prefilled from the current call's message, button set, icon, default button, title and any remaining arguments, and shows a live preview of the statement it will write. Pressing OK replaces the call in place; Cancel changes nothing.

Available when the caret is inside such a call. The BBj language server must be running, because the composer decodes and re-encodes the call through it (#426).
