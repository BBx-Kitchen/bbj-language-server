Opens the BBj tri-state SETOPTS composer for the SETOPTS block at or near the caret.

Available on an absolute SETOPTS <literal> statement, on a canonical var$=OPTS … SETOPTS var$ block built only from IOR/ AND reassignments, or on a line with no existing SETOPTS shape nearby (a new block is composed and inserted). Each option is a three-state Set/Clear/Leave choice; Leave never touches that option. Pressing OK/Insert writes the composed lines in place; Cancel changes nothing.

Any other shape (an intervening non-IOR/AND statement, a branch, an alias) shows why it cannot be safely edited instead of opening the composer. The BBj language server must be running, because the composer decodes and composes the block through it (#475).
