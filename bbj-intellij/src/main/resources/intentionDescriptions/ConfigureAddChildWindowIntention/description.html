Opens the BBj visual composer for the addChildWindow(...) call under the caret.

The composer presents the child window's flag and event-mask hex arguments as named checkboxes (frame and edges, scrollbars, initial state, behavior) with a live schematic of the resulting window. Pressing OK rewrites only the hex literals in place; Cancel changes nothing.

Available when the caret is inside such a call. The BBj language server must be running, because the composer decodes and re-encodes the call through it (#473).
