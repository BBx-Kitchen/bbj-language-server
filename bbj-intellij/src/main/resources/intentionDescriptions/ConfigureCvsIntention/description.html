Opens the BBj visual composer for the CVS(...) call under the caret.

The composer is prefilled from the current call's mask and chars argument when the mask is a sum of integer literals; the string argument being converted is kept verbatim and shown read-only. Pressing OK replaces the call in place; Cancel changes nothing.

On a call that is still being typed -- CVS(, CVS() with the editor's auto-inserted closing parenthesis, CVS(name$ or CVS(name$) -- the composer opens as Complete CVS() call. The string argument is prefilled and editable and there is no assignment field. Applying replaces the unfinished call with one complete CVS(...) call; nothing is written if the line changed meanwhile.

A mask built from a variable or an expression, or one that uses undocumented bits, cannot be edited in place -- no dialog opens, and a notice shows the language server's reason instead. Available when the caret is inside such a call. The BBj language server must be running, because the composer decodes and re-encodes the call through it (#649).
