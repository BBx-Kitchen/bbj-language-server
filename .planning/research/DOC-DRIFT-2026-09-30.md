# Documentation drift after v4.7 (scan 2026-09-30)

Read-only scan of `documentation/`, the READMEs, `CLAUDE.md`, `QA/` and the `package.json` settings
against the code on `main` after v4.7 (PRs #708, #719, #720). About 25 items. Severity: **U** =
user-facing wrong, **D** = developer-facing wrong, **M** = missing coverage of a feature, **C** =
cosmetic. Items marked (v4.7) were introduced by that milestone.

## 1. Build instructions (D, v4.7)
- `README.md:33-37` "Building Locally" says only `npm install`. Since 122, `prepare` is only
  `npm run langium:generate` (`bbj-vscode/package.json:668`), so no build happens and
  `out/extension.cjs` is missing. `README.md:25-29` + `.gitpod.yml:2-4` have the same problem
  (Gitpod init runs `npm install`); `.vscode/launch.json` "Run Extension" has no `preLaunchTask`.
- `README.md:14-17` "two main parts" omits `bbj-intellij` (C).
- `documentation/README.md:7-38` says `yarn` and an SSH/gh-pages `yarn deploy`; the site uses
  `package-lock.json` and deploys via `.github/workflows/deploy-docs.yml` (`npm run build`) (D).

## 2. QA checklists
- `QA/FULL-TEST-CHECKLIST.md:114-116`: EM rows expect EM host/port/username/password settings.
  The only EM setting is `bbj.em.url`; credentials come only from the login prompt and
  SecretStorage/PasswordSafe; `runWeb` has no settings fallback since 112-04 (U, v4.7).
- Missing rows (M, v4.7): remembered EM username; `web.bbj` requires a username, `admin123` only
  for literal `admin` + empty password; expired/undecodable token re-prompt; assign-to
  validation on a new MSGBOX/CVS insert in both IDEs (incl. dropped "(optional)" marker, CVS
  prefilled `s$`); `bbj.formatter.javaPath` set/invalid; workspace `bbj.configPath` in an
  untrusted workspace; invalid interop host/port warning + default fallback; Java hover escapes
  javadoc links except the trailing BASIS Docs link.
- `QA/SMOKE-TEST-CHECKLIST.md:34-35`: "Right-click editor → Run BBj > Run Program"; the VS Code
  editor menu has "Run As BBj Program" directly; IntelliJ's editor menu is direct too, only the
