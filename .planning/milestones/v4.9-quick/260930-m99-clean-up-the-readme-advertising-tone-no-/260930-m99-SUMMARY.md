line. Committed alone as `89a9423f`.

**Task 2 (auto):** Inserted a `## Features` section between Documentation and Requirements via a

validation, live compiler diagnostics (BBj 26.03+), hover/signature help, navigation, Java
integration, run-from-editor shortcuts, visual composers (with its own VS Code/IntelliJ composer
deep links), Enterprise Manager integration, VS-Code-only features (formatting, Denumber,
decompile), IntelliJ-only features (status bar widgets, banners, server log window, Node.js

Committed alone as `d17ea86d`.
