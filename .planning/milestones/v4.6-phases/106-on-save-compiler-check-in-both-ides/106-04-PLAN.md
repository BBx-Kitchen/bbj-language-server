## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| bbjcpl process output → language server | compiler diagnostics for the file on disk are merged into the editor's diagnostics |
| file system → language server | the on-disk text of an open document is read to decide whether bbjcpl checked the editor text |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-106-09 | Tampering (integrity of shown errors) | `debouncedCompile` fallback branch | medium | mitigate | The dedup runs only when `checkedTextIsOnDisk` proves the checked text is the saved text (version match or exact string match with the file), and each dropped complaint must also have identical line text in the validated and checked text; every mismatch publishes today's `mergeDiagnostics` result. Pinned by the unsaved-edits, encoding-mismatch, unreadable-file and stale-line tests. |

| T-106-SC | Tampering | package installs | low | accept | No package install in this plan. |
