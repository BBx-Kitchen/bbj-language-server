### 1. VS Code on-save - open and type
expected: With bbj.compiler.trigger = on-save, opening a BBj file that has a syntax error shows the BBj compiler error without saving. Typing a new invalid line starts no compiler check; only the language server's own syntax error appears for that line.
result: pass

### 2. VS Code on-save - kept errors follow edits
expected: Inserting lines above a flagged line moves the compiler error with its line. Fixing the line without saving keeps the error; saving runs one check at once and clears it. Deleting a flagged line removes its compiler error. Saving with no change runs exactly one check.
result: pass

### 3. VS Code mode switching and auto-save
expected: Switching to debounced starts no check at the switch; typing then checks after about 500 ms. Switching to off clears the compiler errors. With auto-save (afterDelay) and on-save, each auto-save runs one check.
result: pass

### 4. Fallback when BBjServices is stopped

result: pass
