<objective>
Make a crash visible in the right place. The status-bar widget shows a distinct crashed state for
every detected crash, including the first one, until the server is started again (D-10). The editor
banner appears only when auto-restart gives up (D-11). The IntelliJ feature docs describe both.

Purpose: 108-02 records two facts, crashed and gave up. This plan wires each one to exactly one UI
component, so a quiet first crash never raises the banner.
Output: the crashed branch in `BbjStatusBarWidget`, the give-up gate in
`BbjServerCrashNotificationProvider`, two guards, and two doc lines.
</objective>
