<objective>
Stop the false "This statement needs to start in a new line" error on nested single-line IF/ELSE/FI
code the compiler accepts, while a genuinely misplaced ELSE/FI stays flagged (VAL-01, D-01, D-02).

Purpose: `elseStatementLineBreaks` counts an inner group's ELSE as a second claim on an outer IF, so
the outer ELSE of `if a then if b then c=1 else d=1 fi else e=1 fi` is flagged. The same shape
written over `:`-continuation lines is the blank-message A2 group.
Output: a repaired ELSE walker, a regression matrix in `line-break-single-line-if.test.ts`, and new
clean shapes in `single-line-if-forms.bbj`.
</objective>
