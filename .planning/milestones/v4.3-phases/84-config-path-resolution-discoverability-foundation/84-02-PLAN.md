<objective>
Make VS Code treat the resolved config file as a config file regardless of its name or location,
and hold the server-pushed resolved path as the host's warm cache that every other VS Code
consumer reads.

Purpose: CFG-02 and ROADMAP criteria 2 and 3 — the configured file gets config-file highlighting,
composer affordance and tooling, and keeps them across close/reopen and revert.
Output: `src/config-path-cache.ts` (the host cache plus the shared predicates),
`applyConfigAssociation` wiring on four triggers in `extension.ts`, the inactive-config hint in
`setopts-composer-ui.ts`, and a QA row for the manual reopen/revert check.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| language server → VS Code extension host | the pushed `bbj/resolvedConfigPath` payload is stored and drives a language-association side effect |
| workspace settings → extension host | the pre-answer branch reads `bbj.configPath` directly from workspace configuration |
| open document path → comparison | an arbitrary opened file's path is compared against the resolved path |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-84-05 | Spoofing | a workspace-supplied file whose path canonicalizes onto the resolved config path | medium | mitigate | Comparison runs on both sides' canonical forms through the shared `samePath`; a symlink planted inside a workspace resolves to its real target before comparison, so it cannot masquerade as a different file |
| T-84-06 | Tampering | language association applied to an unrelated document | low | mitigate | `applyConfigAssociation` switches a document only when `isActiveConfigPath` is true and only for the `file` scheme; there is exactly one `setTextDocumentLanguage` call site with the config language |
| T-84-07 | Information disclosure | the warning and the inactive-config hint print a filesystem path into the UI | low | accept | The path is the user's own configured value, already visible in the settings UI; no token or credential enters these messages |
| T-84-08 | Denial of service | re-association thrash on every document change | medium | mitigate | `applyConfigAssociation` early-returns when the language id is already correct, so the change-document trigger costs one string compare per edit and never re-enters the language switch |
| T-84-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no package-manager install task and no new dependency; the package-legitimacy gate has no packages to audit |
</threat_model>
