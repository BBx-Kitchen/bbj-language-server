<objective>
Make `::file::Class` scope lookups and PREFIX-document symbol collection stop scaling with total workspace size (RESP-01, #505), proven by a regression test whose hard gate is work counters and whose timing check is deliberately loose.

Purpose: every `::file::Class` reference today streams every BbjClass in the whole workspace index, and every PREFIX document's symbol collection walks (and Java-resolves inside) member bodies the linker never links. Both costs grow with workspace size.
Output: a path-keyed class index in `BBjIndexManager`, a pruned `collectLocalSymbols`, and `test/scope-cost-regression.test.ts`.
</objective>
