<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| dialog form → language server preview | Keystroke-driven preview requests |
| dialog OK → document write | Guarded replace or caret insert |
| server-provided banner/original text → Swing labels | Server strings rendered in the UI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-89-24 | Tampering | a CVS edit applied after the call changed | high | mitigate | `StaleEditGuard.applyIfUnchanged` with a re-issued `cvsDecodeCall` and `DecodeEquality::sameCvs`; the apply-guard source guard pins it |
| T-89-25 | Tampering | an invalid or unavailable preview accepted with OK | medium | mitigate | OK is disabled before the first preview, in `scheduleRefresh`, and on unavailable previews; enabled only on `p.valid`; pinned by the refresh guard |
| T-89-26 | Denial of Service | per-keystroke preview round trips from the new dialog | low | mitigate | `PreviewDebouncer` over `AlarmScheduler` (300 ms), with sequence-checked `ComposerFlow.observe`; the refresh guard lists the CVS dialog as debounced |
| T-89-27 | Tampering | compose-and-replace hiding the discarded expression | high | mitigate | The MSGBOX dialog renders the server banner and the read-only original expression when `replace` is present; pinned by `ComposerReplaceBannerSourceGuardTest` |
| T-89-SC | Tampering | npm/pip/cargo installs | low | accept | No dependency is added |
</threat_model>
