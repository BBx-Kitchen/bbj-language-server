<objective>
Make `./gradlew buildPlugin` on a clean clone fail immediately, with a directed message naming the missing file, when the shared language-server bundle `../bbj-vscode/out/language/main.cjs` is absent — instead of quietly assembling a plugin with no language server.

Purpose: BUILD-03 / issue #517. `copyLanguageServer` is a `Copy` task, and a `Copy` task with a missing source is a silent `NO-SOURCE` skip; the `prepareSandbox` `from(...)` block behaves the same way. The result today is a plugin archive that installs cleanly and then does nothing. One dedicated verification task in front of both consumers turns that into one directed error.

Reading of "immediately": the build fails before any distribution archive is assembled. It is *not* required to fail before `test` runs — `buildPlugin` depends on `test`, and D-10 explicitly forbids making `test` depend on the bundle, so Gradle may schedule the suite first. What must never happen is a completed `buildPlugin` producing a zip with no language server.

Output: a `verifyLanguageServerBundle` Gradle task wired in front of both copy sites, a source-guard JUnit test locking it in place, and a one-line note in `CLAUDE.md`.
</objective>
