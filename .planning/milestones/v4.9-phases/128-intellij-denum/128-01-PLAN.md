<objective>
"Denumber BBj Program" in IntelliJ (IJF-05): declare `bbj/denum` on the plugin's single server proxy
interface with DTOs that mirror `bbj-vscode/src/language/denum-command.ts`, add the action to the
Tools menu and the editor context menu directly after Compile (D-08, D-09, D-10), enable it only on
a BBj program whose text looks line-numbered through a Java port of `isLineNumberedSource` (D-02,
D-11), and send `{uri}` from a background task. The language server presents every outcome and
applies the edit itself through `workspace/applyEdit` (Phase 126 D-10/D-14), which LSP4IJ runs as one
undoable command; the client never saves (127 D-02) and words nothing. The request entry point is a
public static method on the action so the banner in 128-03 runs the same path.

Purpose: one denumber engine for both IDEs; IntelliJ users get the same `bbj/denum` VS Code uses.
Output: `DenumModels`, `BbjComposerServer.denum`, `BbjDenumberAction`, `LineNumbering`, the
plugin.xml action, and five test classes (one edited, four new).
</objective>
