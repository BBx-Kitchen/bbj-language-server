<objective>
The line-numbered-file banner in IntelliJ (IJF-06): a new editor notification provider on the shared
`BbjNotificationProviderBase` (its BBj-program-file-type guard already excludes `config.bbx` and every other type,
D-04) shows "This is a line-numbered BBj program. Denumber it for editing." with a single Denumber link (D-01) when
the Java `LineNumbering` port says the buffer is line-numbered (D-02). The link runs the same
`BbjDenumberAction.denumber` path as the menu action. A project service listens to document changes in BBj files
and, debounced, asks `EditorNotifications` to re-evaluate that file, so the banner goes away once the DENUM edit
lands and returns after an Undo (D-03).

Purpose: a user who opens a numbered program is offered the fix where they are looking, without a prompt.
Output: `BbjLineNumberedNotificationProvider`, `DirtyFileCoalescer`, `BbjLineNumberedBannerRefresher`, two plugin.xml
registrations, a Javadoc count fix on the base, and four test classes (one edited, three new).
</objective>
