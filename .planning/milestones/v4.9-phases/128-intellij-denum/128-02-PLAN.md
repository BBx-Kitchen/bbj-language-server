<objective>
Render DENUM's diagnostics list in IntelliJ (the IntelliJ half of the DEN-04 output, under IJF-05): handle the
server's `bbj/denumDiagnostics` notification by printing one plain-text block into the existing "BBj Language
Server" console, error entries as error output (D-05), and handle `bbj/showDenumDiagnostics` by showing that
tool window scrolled to the latest block (D-06). Entries are plain text with no hyperlinks (D-07), keeping the
Phase 126 contract that no payload field ever becomes a command, link or path. Both handlers live on
`BbjLanguageClient`, so LSP4IJ stops treating them as unsupported. The console content is created before
printing, because `BbjServerService.logToConsole` drops text until the tool window has been opened once.

Purpose: a user who clicks Show after "Denumbered. 1 error." sees exactly what DENUM reported, in both IDEs.
Output: the notification DTOs, `DenumDiagnosticsPresenter`, two handlers, `BbjServerService.scrollConsoleToEnd`,
and four new test classes.
