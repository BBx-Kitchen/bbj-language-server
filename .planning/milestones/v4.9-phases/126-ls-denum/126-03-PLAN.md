<objective>
Give every DENUM outcome its own single message and put DENUM's diagnostics where the user can see
them (DEN-03, DEN-04 server half). After an applied success with diagnostics the server sends the
host-neutral list (D-01, D-04) and shows one combined confirmation with counts and a Show action
(D-03), as a Warning when any entry is an error (D-13); Show sends the reveal notification. Every
failure gets its D-11 text, never deduplicated (D-12).

Purpose: SC3 (one matching message per run) and the server half of SC4. VS Code's rendering of the
list is plan 126-02; the format offer that reaches this code from formatting is plan 126-04.
Output: the outcome table and diagnostics flow in `bbj-denum-service.ts`, three senders in
`bbj-notifications.ts`, the extended harness and `test/bbj-denum-outcomes.test.ts`.
</objective>
