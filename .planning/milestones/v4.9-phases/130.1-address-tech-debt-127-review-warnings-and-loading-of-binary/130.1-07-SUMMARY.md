# Phase 130.1 Plan 07: IntelliJ tokenized-program banner Summary

**IntelliJ now offers Decompile & Replace and Open Read-only on tokenized BBj programs, running the configured BBj Home's bbjlst as `-l [-xlst] -d<private dir> <file>` with an atomic in-place replace, proven against the real bbjlst and fenced by magic-byte and source-guard tests.**

## Accomplishments

- A new `tokenized` package: `TokenizedBbj` probes a path without ever blocking on it (real path first, regular-file check, `NOFOLLOW_LINKS` open, at most 7 bytes read), `BbjLstCommand` is the plain-Java bbjlst core, and `BbjTokenizedDecompiler` is the thin platform glue (background tasks, `GeneralCommandLine` argument list, one "Decompile failed" notification).
- `BbjTokenizedNotificationProvider` extends the shared base (BBj-typed files only), decides from the file's own bytes and offers the two links; registered in `plugin.xml` right after the line-numbered banner.
- The real-bbjlst JUnit case tokenizes a sample with `bbjcpl`, decompiles and replaces `prog.bbj` next to a same-base `prog` sibling: the program becomes source containing the PRINT text, the sibling is byte-identical, the folder holds the same two files and the private directory is gone. It ran (not skipped) on this machine.
- Every failure mode of the VS Code flow is mirrored with the same message texts and tested: not tokenized, missing, not a regular file, unreadable (with cause), no/empty/still-tokenized listing, timeout, unstartable run, failed move.
- Fences: a contract test pins the Java magic to `tokenized-bbj.ts`, a source guard covers the banner, registration and the shell-free launch, and the base-class guard now covers the sixth provider.

## Decisions Made

- `refusal(Probe, name)` is a plain-Java method on `TokenizedBbj` rather than a `switch` in the platform class, so the user-facing texts are covered by unit tests.
- An `AccessDeniedException` is reported as "permission denied": the JDK's own message is just the path, which would read as an empty cause.
- The `-d` directory prefix is a single private constant, keeping the `bbj-decompiled-` literal unique in the package as the guard requires.
- Read-only keeps its private directory only after the copy was handed to the editor; every earlier failure removes it.
