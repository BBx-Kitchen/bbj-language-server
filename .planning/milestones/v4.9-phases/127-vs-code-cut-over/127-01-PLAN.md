<objective>
Move "Denumber BBj Program" (`bbj.denumber`) and the numbered-file open prompt onto the language
server's `bbj/denum` request (DEN-02, DEN-05). The command resolves a target with the existing
no-target guard (D-04), opens the file first when it comes from the Explorer (D-01), and sends
`{ uri }`. The server presents every outcome and applies the edit, leaving the buffer dirty (D-02);
the client words nothing. Command id, menus and Alt+N stay as they are (D-03). The prompt offers
"Denumber" through the same command path (D-05), keeps its client-side detection (D-06) and its
unchanged "Open Read-only" branch (D-07).

Purpose: one denumber engine for VS Code, the same one IntelliJ will use; nothing on this path runs
bbjlst any more.
Output: `src/denumber-command.ts`, the registration in `extension.ts`, the prompt handle and wording in
`open-file-prompts.ts`, and their tests. `Commands.cjs` is not touched here: its denumber member is
removed by the bbjlst plan (127-04) once nothing references it.
</objective>
