<objective>
Attest the Node.js auto-install on real Windows, by hand, against the build that ships.

Purpose: ROADMAP criterion 5 — on a real Windows machine with no Node.js configured, the editor
banner's "Download Node.js" action produces a working `node.exe` beside its `.sha256` sidecar in the
plugin's `bbj-intellij-data/nodejs` directory and the language server starts afterward. This is the
one criterion no Linux-hosted run can close. It has been carried since v4.2 through two milestones,
and leaving it open would carry a major-severity gap into a third.

This plan runs LAST, per the ROADMAP ordering note and D-13: the attestation must exercise a build
that already carries the exact zip-entry match and the guarded temp cleanup from this phase's pipeline
plan, plus the unified resolver and the reason-varying banner, because attesting the old code would
force a re-attestation. Both distributables are built from the final tree first, which is this
project's standing UAT convention.

Output: two installable artefacts built from the phase-final tree, a human attestation with a recorded
outcome either way, and — on failure — a `WINDOWS.md` entry carrying `idea.log` and the directory
contents, per D-15.
</objective>
