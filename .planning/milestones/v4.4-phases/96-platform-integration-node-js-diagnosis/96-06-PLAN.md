<objective>
Point the editor banner at the single engine and delete the other one. The banner currently calls a
separate availability seam that stops dead at a non-empty configured path — so on a machine where the
configured Node.js is broken, the language server starts fine off the cached download while the
banner insists Node.js is required. That seam also checks a minimum version the startup path does
not, giving the two surfaces two different definitions of "usable".

Purpose: ROADMAP criterion 4, the half this phase's engine plan could not close on its own. D-05
makes the resolver the single decision engine; this plan is where the banner actually stops calling
the superseded seam, where the seam and its ten pinned tests are deleted, and where the reason-varying
sentence and action set reach the user.

Depends on the notification base landing first, per the ROADMAP ordering note — the banner change is
written into the shared shape once rather than twice — and on the engine plan, which supplies the
version-gating overload, the inaccessible-cache reason and the presentation seam.

Output: a banner whose diagnosis matches reality, one fewer decision engine in the tree, and a
rewritten source guard pinning the new call shape.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user-configured Node.js path -> banner verdict | A settings string decides what diagnosis a developer is shown. |
| resolver verdict -> offered actions | A decision determines which buttons a user can press, including one that can fail by construction. |
| banner thread and startup thread -> shared version cache | Two surfaces resolving the same path concurrently. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-96-06-01 | Repudiation | banner diagnosis versus actual server state | high | mitigate | Today the banner and the language server can state opposite things about the same machine, because two engines evaluate different rules. | T-96-06-04 | Tampering | deletion of the superseded seam's ten tests | medium | mitigate | Deleting tests can hide a coverage regression.
