<objective>
Close the two small folded todos so 0.16.0 does not ship with known log noise: the IntelliJ client
has no handler for the `bbj/bbjcplAvailability` notification the shared language server sends once per
session (LSP4IJ warns on every server start), and `BbjNodeDownloader` calls `setFraction` on an

during every Node.js download.

Purpose: both are user-visible in `idea.log` and both are one-line fixes with an existing guard file
to pin them.
Output: one no-op notification handler, one indicator-mode call, two source-guard assertions.
