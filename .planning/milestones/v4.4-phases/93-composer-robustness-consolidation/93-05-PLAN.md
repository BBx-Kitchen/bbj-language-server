<objective>
Make a malformed or partial `bbj/composer/catalogs` response degrade to the same graceful "not ready"
message a fully-null response already gets, instead of an IDE Internal Error balloon.

Purpose: COMP-03 (#609). `ComposerFlow` already guards a null `catalogs` payload, and each `open*`
method in `ComposerLauncher` already guards its own null per-kind object. Neither guards the
sub-lists: every dialog constructor iterates one or more of them immediately, so a response whose
`byteGroups`, `bits`, `flags`, `eventBits`, `icons`, `buttonSets` or `defaultButtons` is null throws
a `NullPointerException` on the EDT inside the dialog constructor. Per D-01 this covers the whole
present-day family of six dialogs, not the three #609 names.
Output: a plain-Java `ComposerCatalogsCheck`, six gated construction sites, and two test files.
</objective>
