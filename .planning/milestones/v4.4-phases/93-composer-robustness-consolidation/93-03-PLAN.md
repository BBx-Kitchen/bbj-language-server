<objective>
Stop a malformed language-server edit range from crashing the IDE mid-write, and give the user a
named reason when it happens.

Purpose: COMP-05 (#591). `ComposerLauncher` indexes `[0]` and `[1]` on four language-server-supplied
range arrays with no length check. Two of them (`flagsRange`, `eventMaskRange`) are the ones #591
names; per D-01 and D-10 the same bug class lives on `hexRange` at both SETOPTS write paths, and one
of those has no null check either. An `int[]` of the wrong length throws
`ArrayIndexOutOfBoundsException` from inside a `WriteCommandAction` on the EDT, which surfaces as an
"IDE Internal Error" balloon.
Output: a plain-Java `ComposerEditRanges` predicate, a fourth `ComposerNotices.Reason`, four guarded
call sites, and three test files.
</objective>

| Boundary | Description |
|----------|-------------|
| language server → `ComposerLauncher` write paths | an untrusted-shape `int[]` crosses into document offset arithmetic |
| `ComposerLauncher` → developer's source file | a write command mutates live source on the EDT |
