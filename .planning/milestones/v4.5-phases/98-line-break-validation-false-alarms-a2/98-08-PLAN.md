<objective>
Close verification gaps 3 and the WR-01 caveat: two narrowings this phase made silently dropped real
detection capability, with nothing in the shipped suite guarding either.

The single-line IF/FI/ELSE backward walks were taught to step over a same-line closer so a nested
chain finds its true governing IF. They step over closers without counting them, so a non-nested
shape whose only IF was already closed is now accepted. Separately, the conflicting-DECLARE check now
requires both types to resolve to a class, which silently drops a BBj scalar-type mismatch whenever
no Java classpath is loaded — this project's own default test and development case.

Purpose: each phase criterion is "no error on code the compiler accepts", never "no error" (D-14).
A fix that buys a true-positive back by giving up a different true positive has not met it.

Output: balance bookkeeping in both walks, three still-flagged regression cases, a scalar-vs-scalar
short circuit in the DECLARE check, and the test that proves it fires without a classpath.
</objective>
