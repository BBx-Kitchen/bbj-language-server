<objective>
Watch the feature work, watch the fallback work, and ship the branch.

Purpose: PSRV-03 and PSRV-04 are statements about what a developer sees in an editor. Both halves
are already automated hermetically, but "behaves exactly like 0.16.x" is a claim about two real IDEs
against a real older server, and the only honest way to close it is to build both distributables
from the final tree, swap the pre-endpoint jar back in once, and look.
Output: two staged hand-verification blocks the end-of-phase verifier harvests, with evidence quoted from real logs, a green suite, a clean
register check, a pushed branch and an open pull request.

**Overlap is expected, not a defect.** With the endpoint live, a line can carry both a live parser
diagnostic and a save-time compiler diagnostic. That overlap is accepted in this phase and is
removed in the next one — the tester must not file it.
</objective>
