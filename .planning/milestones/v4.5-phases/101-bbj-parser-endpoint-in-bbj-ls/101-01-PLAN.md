architectural dead end costs one commit instead of ten.

JUnit test classes — one live-socket, one in-process.

**Naming note (planner decision, test names are discretionary under D-15):** the live-socket
class is `ParseProgramIntegrationTest`, not `ParseProgramIT` as the validation seed and the
pattern map sketch it. Maven Surefire's default includes are `Test*`, `*Test`, `*Tests` and
`*TestCase`; an `*IT` class is Failsafe's convention and Surefire would silently skip it, so a
bare `mvn test` would report green while never running the integration suite at all. Renaming
keeps research's verified "no Surefire configuration needed" property true instead of trading it
for a pom plugin block.

authored across the four plans, each in the plan that makes it true): encoding → plan 01;
empty input, output ordering, empty prefix/root lists, referenced-program byte handling → plan 02;
adjacency of identical version tokens, per-connection concurrency, supersession → plan 03. Plan
04 exercises them.

<assumption_delta_decision>
**Noun:** "another file" — the programs the active document `USE`s or `CALL`s.
**Decision:** add-alongside.
**Rationale:** the request stays single-document (`text` + `canonicalName`, one in-memory source);
referenced programs remain a separate, disk-sourced concept resolved by the prefix algorithm
(D-07, D-09). The active document is NOT promoted to a list of documents — an overlay of other
open buffers is an explicitly deferred idea, and promoting the field now would change the wire
contract that D-01/D-04 fix as one-way.
</assumption_delta_decision>
