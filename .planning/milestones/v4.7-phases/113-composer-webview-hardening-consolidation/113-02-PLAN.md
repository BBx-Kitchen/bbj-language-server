<objective>
Every composer webview checks the shape of each message it receives before anything acts on it
(SEC-10, issue #604, amended by D-01 to all six webviews). A small dependency-free primitives
module holds the type checks once; each webview gets its own `is…PanelMessage` guard next to its
`Selection` type and returns silently from its handler when the guard fails.

Purpose: the extension host holds full workspace-edit power; a broken or compromised webview
script must not be able to push wrongly typed data into `build()`, a language-server request or a
WorkspaceEdit (today a payload of `{}` throws inside `build()`).
Output: `src/webview-message-guard.ts`, six guarded handlers, two new test files.
</objective>
