<objective>
DEP-01 (#501): the production dependency set of the VS Code extension holds only what the
extension runs. `@vscode/vsce` is a packaging CLI that is never imported by `src/` or bundled by
esbuild. It moves from `dependencies` to `devDependencies`, and the lockfile is regenerated so that
vsce and the packages only it pulls in are flagged dev. `.vscodeignore` already excludes
`node_modules`, so the VSIX contents do not change; the plan proves this instead of assuming it.

Purpose: `npm ls --omit=dev` and production-scoped advisory tooling stop tracking a packaging tool
that never ships to users.
Output: a two-line manifest change and a lockfile whose diff only adds dev flags.
</objective>
