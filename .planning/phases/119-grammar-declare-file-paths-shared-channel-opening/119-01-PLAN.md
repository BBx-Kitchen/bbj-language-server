<objective>
FIX-01 (#527). The `BBjFilePath` terminal in `bbj.langium` is greedy (`.*`). On a line with two
file-path-qualified class references it matches through to the last `::`, so
`declare ::lib1::ClassA a; declare ::lib2::ClassB b` parses as one declaration with no error at all.
This plan records everything the phase compares against while the grammar is still the base
(error sets, tokens, AST shapes, whole-suite failing names, a parser-mode corpus run). It then pins the
misparse with a test that fails on the base (D-05), makes the terminal non-greedy (D-04), and
regenerates under Node 22. A regression file (D-06) and a targeted test (D-07, D-08) prove the
result, and every difference from the base is attributed to the #527 shape (D-09, D-10).

Purpose: two class references with library paths on one line silently lose the first declaration,
merge two USE statements into one, and swallow the IMPLEMENTS keyword into the EXTENDS path. None of
these produce a diagnostic today.
Output: the one-line terminal change, `test/test-data/issue527-declare-file-paths.bbj`,
`test/declare-file-paths.test.ts`, and base-vs-fix evidence kept outside the repository and
summarized in the SUMMARY.
</objective>
