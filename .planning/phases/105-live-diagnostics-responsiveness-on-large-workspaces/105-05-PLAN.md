<objective>
Measure the fix where the problem lives, write it down, and grow the milestone pull request.

Plans 01-04 prove the mechanics hermetically. Whether a developer on a real, large workspace now
sees BBj's verdict while the startup build is still running — in VS Code and in IntelliJ — can only
be shown on the private `bbj-corpus`, against real BBjServices, before and after. This plan gates
the final tree, builds both distributables twice (phase base and final tree), stages a measurement
runbook, stops for the tester to run it, then records the numbers and carries them into PR #691.

Output: `105-MEASUREMENT.md`, two installed-ready distributable pairs, the pushed branch and an
updated PR #691.

   instrumentation is added to the language server.

   today). The comment that closes #692 is drafted verbatim in `105-MEASUREMENT.md` now and posted

   tests, and Phase 103 already hand-checked the pre-endpoint path.
