<objective>
Open the tracker: run the D-07 live dedup re-query, then create the nine private draft security
advisories — starting with one, verified, before the other eight.

Purpose: this is the first plan in the milestone permitted to write to the tracker, and it deliberately
writes to the reversible end of it first. A draft security advisory is private and deletable; a public
issue is not. Proving the whole write path — slice the approved body, post it, read it back, append the
ledger row — on one private, deletable entry costs one create and buys certainty before the one-way
writes begin in `69-10`.

Output: `69-FILING-LEDGER.md` with the approval record, the re-query result and nine rows;
`69-TRACKER-SNAPSHOT.txt`; and nine draft advisories on the repository.
</objective>
