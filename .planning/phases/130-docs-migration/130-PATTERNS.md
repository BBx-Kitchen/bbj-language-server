## Shared Patterns

### Verbatim strings, never invented
**Source:** `130-RESEARCH.md` Section A (messages) and Section B (settings, IntelliJ labels).
**Apply to:** both formatting pages, both message tables, QA expected-result cells, release notes. Setting prose is paraphrased once from `bbj-vscode/package.json` and reused.

### MDX safety
**Apply to:** every `.md` under `documentation/docs/`. Backtick every `{...}`/`<...>`; pasted formatter output only in fenced blocks; `.md` is parsed as MDX.

### Link style
**Apply to:** all guide pages. Quick-link tables: `vscode/getting-started` (no `./`, no `.md`). In-page links: `[Opening Programs](./configuration.md#opening-programs)`. `onBrokenLinks: 'throw'` (`documentation/docusaurus.config.ts:22`); anchors may only warn, so check by eye.

### Banned content (gates)
**Apply to:** `documentation/docs/**`, `QA/*.md`, `bbj-intellij/build.gradle.kts`, README.
- No `javaPath`, `BBjCFCli`, `BBjCodeFormatter`, formatter jar; bbjlst only on Decompile lines.
- No "denumber and replace" / "replacing the file with editable" wording.
- No planning ids (`D-NN`, `MIG-0N`, `12x-NN`, `130-NN`).
- No closing keywords (`Closes`/`Fixes`) for #507 or lsp4ij #381 anywhere, including commit bodies.
Gate commands: RESEARCH "Validation Architecture" table.

### QA row grammar
**Apply to:** both checklists. `| # | Feature | Steps (1. … <br>2. …) | Expected | [ ] |`; append, do not renumber; samples embedded in the row text (no numbered fixture exists in `examples/`).

### Docs build gate
