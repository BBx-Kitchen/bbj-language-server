<objective>
Make every VS Code MSGBOX entry point safe to use on a call the user is still editing (DISC-08, #532, plus the folded MSGBOX nesting todo).

This plan:
- gives an unfinished `MSGBOX(` / `MSGBOX()` / `MSGBOX("Hi",` call its own `incomplete` decode outcome in the shared server module;
- opens a `Complete MSGBOX call` panel for it, with no banner and no assign-to row, and replaces the call span through a span-exact staleness check;
- makes the QuickPick picker's `edit` and `insert` branches re-resolve their target immediately before writing and abort on any mismatch;
- makes `Compose MSGBOX (visual)…` and `Compose MSGBOX…` position-aware so no palette or context-menu entry inserts a statement inside an existing call.

Purpose: a document edit during the wizard, or a composer opened on a half-typed call, can never corrupt unrelated text or nest a call.
Output: the decode outcome, the panel mode, the guarded picker, position-aware commands and their tests.
</objective>

`MsgboxDecodeCallResult` gains `incomplete?: boolean`. A MSGBOX call with no message yet (`MSGBOX(`, `MSGBOX()`), or whose options slot is open but empty (`MSGBOX("Hi",`), decodes as found true, incomplete true, with `edit`, `initial`, `trailingArgs` and `hasOptions: false`, and never with `replace`:
- `{ line: 'x = MSGBOX(', character: 11 }` → `{"found":true,"incomplete":true,"edit":{"callStart":4,"callEnd":11},"trailingArgs":[],"initial":{"message":"","title":"","buttonSet":0,"icon":0,"defaultButton":0,"flags":[],"customButtons":[]},"hasOptions":false}`
- `{ line: 'x = MSGBOX()', character: 11 }` → the same, with `callEnd` 12
- `{ line: 'x = MSGBOX("Hi",', character: 16 }` → the same shape, `callEnd` 16, `message` `"Hi"`
- `{ line: 'x = MSGBOX("Hi", , "T")' }` → incomplete, `message` `"Hi"`, `title` `"T"`
- `r = MSGBOX("Hi")`, `r = MSGBOX("Hi", 36, "T")` and `r = MSGBOX("Hi", flags%, "T")` carry no `incomplete` key; their payloads are unchanged.

Labels: lightbulb action `Complete MSGBOX call…`; VS Code panel title and IntelliJ dialog title `Complete MSGBOX call`; stale warning `The MSGBOX() call changed since the composer opened; nothing was applied.`

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| document text at open → document text at write | The user (or another extension) can edit the document while the wizard or panel is open |
| command argument → editor write | `bbj.composeMsgbox` is callable with an arbitrary `edit`/`insert` argument |
| webview message → extension edit | The panel posts `insert` payloads that the extension turns into a document edit |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-90-01 | Tampering | `runComposer` edit/insert write after the document changed during the QuickPick wizard | high | mitigate | `captureComposeArgTarget` at open plus span-exact `msgboxCallStillMatches` immediately before `editor.edit`; abort with a warning; #532 regression tests for inserted lines, changed text, a grown call and a vanished line |
| T-90-02 | Tampering | completing-mode panel `insert` after the unfinished call grew | high | mitigate | span-exact check re-locates the call with `findMsgboxCalls` and refuses any span change; panel test with a grown line |
| T-90-03 | Tampering | palette or context-menu compose-new inserting a statement inside an existing call | medium | mitigate | `runComposeMsgboxVisualCommand` and the picker hand-off decode the cursor first; tests for unfinished, decodable and undecodable calls |
| T-90-04 | Tampering | a command argument whose `exprRange` or insert offset no longer describes the document | medium | mitigate | consistency check at open (exprRange, exprValue, optionInsertOffset); no wizard opens on a mismatch |
| T-90-05 | Tampering | crafted `insert` payload from the webview with an invalid message | low | mitigate | the existing extension-side `if (!r.valid) break;` stays first in the handler |
| T-90-SC | Tampering | npm/pip/cargo installs | low | accept | No dependency is added |
