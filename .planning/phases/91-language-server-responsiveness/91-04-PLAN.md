<objective>
Stop LRU eviction during a class's own cyclic resolution from producing a 30-second stall or a stub for a class that resolves (RESP-03, #497). Prove that the guard state drains once everything settles.

Purpose: `resolveClass` registers a class in the LRU before its async Phase 2. A cyclic member type later relies on that entry to break the cycle. `loadImplicitImports()` calls `resolveClass` directly and resolves many packages concurrently, so the entry can be evicted mid-flight. The cycle then refetches the class, and the refetch waits out a timeout.
Output: an in-flight registry beside the LRU, a cache-limit test seam, and regression tests.
</objective>
