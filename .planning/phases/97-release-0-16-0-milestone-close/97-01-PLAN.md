<objective>
Move the authoritative language-server status feed from `BbjLanguageClient` (which LSP4IJ nulls out
before it publishes `ServerStatus.stopped` after an unexpected stop) to the `LSPClientFeatures`
subclass returned by `BbjLanguageServerFactory.createClientFeatures()`, which LSP4IJ always calls.
This is folded todo 1: today a lost language-server connection is invisible to the plugin's crash
detection because the CRASH branch never runs.

Purpose: 0.16.0 must not ship with crash detection that cannot see the crash it exists to detect
(D-07). The hand UAT that proves it end-to-end in a running IDE is plan 97-05's blocking checkpoint.
Output: one new override, one reduced override, one allowlist entry, one new reflective canary and
two new source-guard assertions.
