<objective>
Make every VS Code consumer of the config path read the one resolved answer: the Show-config
command, the four run paths, and the compiler's `-c` option.

Purpose: CFG-01 — the configured config file, of any name and location, is honored by run and
compile commands and by the Show-config command, not just by PREFIX resolution.
Output: cache-backed `openConfigFile`/`run`/web-run in `Commands.cjs`, a sentinel guard in
`buildRunArgv`, an updated setting description and command title in `package.json`, and a
resolved-path-aware `-c` reader for `bbj/compile`.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| resolved config path → spawned `bbj` process argv | the path becomes a `-c` element passed to the BBj executable |
| resolved config path → spawned `bbjcpl` process argv | the same path becomes a `-c` compiler option |
| resolved config path → EM registration script | the web-run path writes the config path into the registered EM application |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-84-09 | Tampering | argv construction in `buildRunArgv` / `buildWebRunArgv` | high | mitigate | Arguments are pushed into an array and launched through `execFile` (never a shell), so a path containing shell metacharacters is a single opaque argv element; the existing no-shell-command-construction and command-argv-injection tests continue to gate this |
| T-84-10 | Tampering | EM Config sentinel reaching a `-c` element | high | mitigate | Guards in both `buildRunArgv` and `buildWebRunArgv` refuse the sentinel, layered on the resolver's central neutralization; a test asserts the resulting argv holds no `-c` element for sentinel input |
| T-84-11 | Elevation of privilege | `bbjcpl` reading an attacker-chosen config file | medium | mitigate | The injected `-c` value can only be the resolved path, which is canonicalized and absolute; injection is skipped entirely when the user has set an explicit config-file option or prefix directories |
| T-84-12 | Information disclosure | the Show-config error message printing a filesystem path | low | accept | The path is the user's own configured value, already visible in the settings UI |
| T-84-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no package-manager install task and no new dependency; the package-legitimacy gate has no packages to audit |
</threat_model>
