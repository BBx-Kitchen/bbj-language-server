<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| cached config path → spawned BBj process argv | the path becomes a `-c` element on the GUI run's command line |
| cached config path → web-runner script parameters | the BUI and DWC runs pass the path into the registration stub, which writes it into the EM application |
| settings text field → filesystem probe | an arbitrary user-typed string is stat-ed by the settings lookup |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-84-21 | Tampering | EM Config sentinel reaching a `-c` argument on the plain GUI run | high | mitigate | `ConfigPaths.configPathArg` short-circuits the sentinel exactly as the classpath sibling does, and a test asserts a null return for that input; the GUI run has no downstream script to absorb it, which is why this is the highest-value guard in the plan |
| T-84-22 | Tampering | an empty or sentinel path written into the EM application registration | high | mitigate | The BUI and DWC actions abort with a named message when the path is blank rather than passing it through, preserving the real-path requirement of issue #382 |
| T-84-23 | Information disclosure | the config path printed into a run notification | low | accept | The path is the user's own configured value; the plugin's existing rule that secrets travel on the environment and never in argv is unchanged by this plan |
| T-84-24 | Denial of service | the settings validator stat-ing a path on every keystroke | medium | mitigate | The probe runs through the existing debounced lookup seam on the single shared scheduler; the validator itself reads only a cached result, and the component's source-guard test enforces that it does no filesystem work inline |
| T-84-SC | Tampering | npm/pip/cargo installs | high | mitigate | This plan adds no package-manager install task and no new dependency |
</threat_model>
