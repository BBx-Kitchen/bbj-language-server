<objective>
Let the missing-USE quick fix and auto-import completion insert a class name only when it is a Java
qualified name, dropping any other candidate silently while the next valid one keeps the preferred
flag (issue #525; D-09, D-10).

Purpose: both features build `use ${fqn}\n` from class names the interop peer supplied; a name with a
line break and BBj statements (for example Foo, a line feed, RUN "x.bbj") would be inserted into the
user's source, and the top candidate is applied directly by VS Code's Auto Fix.
Output: `isJavaQualifiedName` in the shared module, the filter in both call sites,
`test/java-qualified-name.test.ts` and new cases in `test/code-action.test.ts`.

Canon breadcrumb: inserting unvalidated text through a TextEdit is a canon injection pattern; it is
handled in the threat register, not minted as a separate prohibition.
</objective>
