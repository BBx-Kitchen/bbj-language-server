<objective>
Bound and type-check every field of a java-interop peer class description before it is stored on the
`JavaClass` node (issue #523), through one shared plain module that later plans in this phase extend
(D-01..D-05).

Purpose: `resolveClass()` copies peer fields onto the AST unchecked, so a broken or compromised peer
can store multi-megabyte strings, crash resolution with a wrongly typed field, or poison the package
tree. The guard sits at the entry of `resolveClass()` so the bulk implicit-import path is covered too.
Output: `java-peer-guard.ts`, a guarded `resolveClass()`/`loadImplicitImports()`, Phase-2 javadoc and
parameter-name bounds, and `test/java-interop-peer-guard.test.ts`.
</objective>
