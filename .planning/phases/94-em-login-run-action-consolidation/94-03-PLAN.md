<objective>
Give the EM login action the enablement override it never had, and pin the temp-file cleanup scope
that nothing currently protects.

`getActionUpdateThread`, so it is unconditionally enabled and its presentation is computed on the
default thread — that missing pair is #589's real finding. EM-01 is a different shape: commit
`06eb1a7c` already restructured the launch so the `finally` covers it entirely, and the failure #590
describes cannot occur today; but nothing pins that scope, and the invariant regressed once already.
This plan closes #589 with code and #590 with a guard.
Output: two small overrides on the login action, and two new source guards.
</objective>
