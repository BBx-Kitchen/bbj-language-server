|----------|-------------|
| language server → IntelliJ plugin (LSP4IJ JSON-RPC) | Server-supplied JSON is deserialized into Java DTOs by LSP4IJ's `MessageJsonHandler`; a field rename or an out-of-range number arrives as untrusted input |
