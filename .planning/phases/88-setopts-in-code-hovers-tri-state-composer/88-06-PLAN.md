## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| language server → VS Code extension host | The decode result decides whether an edit is offered and what range it covers |
| webview → extension host (`postMessage`) | The webview's form state is untrusted script-context input crossing into the extension host |
| extension host → user's document (`WorkspaceEdit`) | The only place this plan writes into a user's file |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-88-01 | Tampering | command routing on `editable: false` | high | mitigate | The not-editable branch shows a message and returns; no panel is opened and no `WorkspaceEdit` is constructed, pinned by a named test |
| T-88-02 | Tampering | composed block content | high | mitigate | The block text always comes from `composeTriState`; an acceptance grep asserts the client never calls `setoptsPreview` in the tri-state panel, so no client-side arithmetic can disturb an unmodelled bit |
| T-88-12 | Tampering | chain replacement range | high | mitigate | The replacement spans only `[startLine, endLine)` supplied by the server; the equal-line case inserts rather than replacing, pinned by a named test |
| T-88-14 | Tampering | webview script context | medium | mitigate | The panel keeps the existing SETOPTS webview's CSP and per-load nonce discipline; the extension host treats every posted payload as data, forwarding the selection to the server rather than evaluating it |
| T-88-15 | Denial of Service | request failure handling | low | mitigate | Every request is wrapped so a rejection surfaces as a non-blocking message instead of an unhandled rejection in the extension host — the same defect class `test/extension-activation.test.ts` was written for |
| T-88-SC | Tampering | npm installs | high | accept | This plan adds no npm dependency; 88-RESEARCH.md §"Package Legitimacy Audit" records the phase as not applicable |
