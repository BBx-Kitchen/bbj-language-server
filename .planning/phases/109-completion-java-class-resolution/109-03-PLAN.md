<objective>
Give a call to an overloaded BBj or Java method the return type of the overload its arguments match,
in type inference only (COMP-02, issue #556, D-05), with a conservative no-type answer when the arguments
do not decide (D-06).

Purpose: the linker picks the first-yielded same-named declaration, and the type inferer reads that
declaration's return type without looking at the arguments, so completion and checks on the result use
the wrong type.
Output: shared argument-type derivation and node-preserving overload selection in
`bbj-overload-selector.ts`, the re-selection in `bbj-type-inferer.ts`, the inlay provider delegating, and
`test/overload-return-type.test.ts`.
</objective>
