Make completion after a fully-qualified Java class reference typed without `USE` offer only static members
(plus `class`), exactly as it already does after a `USE`d class name (COMP-01, issue #577, D-11).

Purpose: `java.lang.String.` parses as a chain of `MemberCall` nodes, never a `SymbolRef`, so today's
class-reference detection misses it and instance members leak into the list.
Output: one extra detection branch in `bbj-scope.ts` and `test/completion-class-reference.test.ts`.
</objective>
