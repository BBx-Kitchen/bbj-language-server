<objective>
Delete the inert Color Scheme page. `BbjColorSettingsPage` declares nine `TextAttributesKey`
constants and a demo-text preview, but BBj highlighting is driven entirely by TextMate, which applies
theme defaults directly — so every colour a user customises on that page is ignored. The page's own
class javadoc admits this, deferring to a semantic-token integration that was never built.

Purpose: ROADMAP criterion 2 offers two branches — make the page work, or remove it so it cannot
mislead. D-01 takes the second branch, because the first is unreachable: CONTEXT.md correction 5
establishes that IntelliJ's TextMate engine resolves scopes through its own theme mapping with no
supported extension point for a third-party plugin to remap them, and the language server's existing
semantic-token provider emits only three of the nine descriptors this page declares.

Output: one deleted class, one removed registration, one rewritten documentation section, and #621
closed on cited reasoning (D-04) rather than as partially implemented.
</objective>
