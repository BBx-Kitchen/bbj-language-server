<objective>
Stop the "needs to end with a line break: DEF" false alarm on the eleven files whose real shape is
a multi-line `DEF FN` function that is never closed by `FNEND` and runs to the end of the file.

Purpose: research's original reading — a header spread over continuation lines — was wrong, and the
Orchestrator Addendum corrected it (D-18). Ten of the eleven files contain no `FNEND` at all; the
eleventh has earlier, properly closed functions and one unclosed final one. The compiler accepts
this. Today `DefFunction`'s multi-line alternative demands an `FNEND` that never arrives, so
Chevrotain silently prefers the fallback expression-statement interpretation of the header and the
line-break check reports the symptom. The fix is at the root, in the grammar (D-01).

Output: an optional `FNEND` on the multi-line `DEF FN` alternative, a `def-fn-unclosed-body.bbj`
conformance fixture, and positive plus still-flagged cases in `line-break-validation.test.ts`.
</objective>

## Flagged Assumptions

- **VALID-03 / unclassified edge (unresolved).** The edge probe could not classify VALID-03 into a
  named edge category, so no acceptance criterion was auto-derived for it. Surfaced rather than
  invented: what should happen when an unclosed `DEF FN` body is followed by a class declaration,
  an interface declaration or another `DEF FN` is not specified by any source artifact. Those three
  are not `Statement` alternatives, so they should end the body naturally; Task 1 probes and pins
  that behaviour rather than assuming it.
- **Behaviour change beyond the corpus shape.** Making `FNEND` optional means an accidentally
  unclosed function silently swallows the rest of its file into the function body, where
  `isStandaloneStatement` reports nothing. That is what the compiler does, so it is correct — but
  it is a real reduction in reporting for a typo'd file. Recorded here deliberately; it is not a
  reason to keep the false alarm.

Probe-item accounting for this plan: 1 surfaced for this requirement = 0 authored into
`must_haves.truths` + 1 flagged above.
