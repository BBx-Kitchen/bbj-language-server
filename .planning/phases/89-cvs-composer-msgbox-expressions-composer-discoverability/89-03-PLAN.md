<objective>
Build the editor-agnostic CVS() composer domain (DISC-03, #649) and fix the built-in `CVS()` signature,
so that every call the composer writes passes the language server's own argument-count check (Research
Pitfall 1 — a hard prerequisite for the `chars` field).

The module follows the addWindow and SETOPTS composer shape:
- a catalog with `since`-style annotations and a `charsCustomizable` flag (D-12);
- one preview function that every UI calls;
- literal-sum recognition for edit-in-place (D-14);
- no client-side version gating of `chars` (D-13).
No `vscode` import, so the language server (plan 89-07) and the VS Code UI (plan 89-05) share it.

Purpose: DISC-03 (#649).
Output: `functions.ts` and `functions.bbl` widened together, `cvs-composer.ts`, and unit plus validation tests.
</objective>
