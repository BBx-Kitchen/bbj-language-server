**The anti-vacuous check.** Before committing each D5 test, break the behaviour it covers in the
working tree (invert a condition, return a constant), run the test, confirm it goes RED, then
`git checkout --` the source file and confirm the test goes GREEN again. Record the observed red

only the observation is. A test that stays green against the broken source is vacuous and must be
rewritten before it lands.
