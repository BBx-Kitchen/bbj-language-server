## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| file system → extension host / IDE | A user-chosen file is probed (realpath, lstat, 7-byte read) before anything else happens | file bytes and paths (local, user-owned) |
| extension host / IDE → bbjlst | `bbjlst` is launched with an argv array, never through a shell, writing into a private temp directory | file path, decompiled listing |
| decompiled listing → user's program | The listing is staged next to the target and atomically renamed over it | program source (user data, integrity-sensitive) |
| language server → client | Denumber notification payload (uri, version, diagnostics) | document identity and version |
| VS Code activation → language server / Java interop | Since this phase the server and interop start only for a BBj document or an explicit command | process spawn, localhost socket |
| build → distributables | The plugin zip must carry the tested language server | `main.cjs`, plugin jar |

| AR-01 | T-130.1-18 | Java has no non-blocking open. The window lies between two calls on a path the user chose, and the work runs on a background thread, off the EDT, so the IDE stays responsive. **Corrected wording:** the progress task is *not* cancellable (`BbjTokenizedDecompiler.java:62,73`, `canBeCancelled = false`), so a blocked open leaves the "Decompiling…" task hanging until the IDE restarts. IntelliJ strips the path from permission errors. Nothing leaves the machine. | planned (130.1-02) | 2026-10-05 |
| AR-03 | T-130.1-31 | The boxed `Long` `version` is not acted on in IntelliJ (the list is only logged). A lenient adapter (`DenumModels.java:67-68`) reads non-integers as null without rejecting the list. | planned (130.1-08) | 2026-10-05 |
| AR-04 | T-130.1-33 | QA steps that create symlinks and tokenized copies run in a scratch folder the tester chooses, on the tester's own machine, with single `bbjcpl` / `ln -s` commands and no pipes. | planned (130.1-09) | 2026-10-05 |
