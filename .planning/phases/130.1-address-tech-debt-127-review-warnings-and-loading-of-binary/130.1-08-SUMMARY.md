# Phase 130.1 Plan 08: IntelliJ tokenized-file filter and DENUM notification version Summary

**IntelliJ declines to connect tokenized BBj programs to the language server through a stamp-cached seven-byte check in LSPClientFeatures.isEnabled(VirtualFile), and the DENUM notification model carries the optional document version with a lenient Gson adapter.**

## Accomplishments

- A tokenized program is never announced to the shared language server from IntelliJ, so the server no longer parses a large binary (measured 5.2 s for 1.45 MB). After Decompile & Replace the editor reopens, the cached verdict is recomputed from the new modification stamp, and LSP features return.
- The check reads at most seven bytes once per file content, and never throws, so it is safe on the EDT.
- `DenumDiagnosticsParams.version` exists on the IntelliJ side and the contract test pins it next to the TypeScript field; rendering is identical with and without it.
- Whole IntelliJ suite after a fresh language server build: 1363 tests, 0 failures, 0 errors, 0 skipped.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] A plain boxed Long rejects the whole notification for a fraction or boolean version**
- **Found during:** Task 2 (GREEN run of the new boundary test)
- **Issue:** The behavior spec says a version of `"7"` or `1.5` must not reject the notification. With a bare `public Long version;`, LSP4J's Gson threw `MessageIssueException` ("Message could not be parsed") for the non-integer cases, which would drop the whole diagnostics list.
- **Fix:** Added a small `LenientLongAdapter` (nested in `DenumModels`) and put `@JsonAdapter(LenientLongAdapter.class)` on the field. The field declaration still reads `public Long version;`, so the plan's artifact and the contract test's field regex still match. Whole numbers and numeric strings parse; everything else reads as null.
- **Files modified:** `DenumModels.java`
- **Verification:** `DenumModelsJsonBoundaryTest.aNotificationVersionOfAnotherJsonTypeDoesNotRejectTheList` covers `"7"`, `1.5`, `null`, `true`; the whole suite is green.
- **Committed in:** `063d0def`
