<objective>
Both IDE login prompts pre-fill the last successfully used Enterprise Manager username, or `admin` when
none is remembered (D-08, the IDE-side half of the SEC-12 ruling that removed web.bbj's username
default). VS Code keeps the username in `context.globalState`, IntelliJ in the application-level
`PropertiesComponent`; it is saved only after a successful login, and passwords and tokens are never
stored this way.

Purpose: web.bbj no longer fills in `admin`, so a user who is not `admin` should not have to retype
their name on every login; today both prompts hard-code `admin`.
Output: `src/em-username-memory.ts`, the `bbj.loginEM` wiring, `test/em-login-username.test.ts`,
IntelliJ `EmUsernameMemory.java`, the `BbjEMLoginAction` wiring and two JUnit 5 test classes.
</objective>
