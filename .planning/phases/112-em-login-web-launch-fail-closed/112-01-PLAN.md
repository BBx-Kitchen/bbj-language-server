<objective>
Make `bbj-vscode/tools/web.bbj` fail closed (issues #546 and #548): no default username, `admin123`
only for the exact user `admin` with an empty password, and every Enterprise Manager step after login
reports its own failure through one shared MSGBOX reporter that ends with a non-zero exit code

call after login that fails ends the hidden-console program with no message. The same file is bundled
into the IntelliJ plugin unchanged, so this plan fixes both IDEs at once.
Output: the rewritten `tools/web.bbj` and `test/web-bbj-source-guard.test.ts`.
</objective>
