From bbj-vscode/src/language/java-interop.ts (read this session; do not change it):
- `protected async connect(): Promise<MessageConnection>`: returns the cached connection, else the breaker checks, else `establishConnection()`, which is `createSocket()` then `wrapSocket(socket)`, then `onClose`/`onError` handlers, then `listen()`, then `_connectionGeneration++`. On a socket failure it logs `console.error('Failed to connect to the Java service.', e)` and rethrows. `connect()` wraps the failure in `InteropTransportError(message)`, whose class is exported.
- `protected createSocket(): Promise<Socket>`: a `new Socket()` with a 10000 ms guard (`'Socket connection to Java service timed out after 10s'`) that rejects on `'error'`, resolves on `'ready'`, and connects to `interopPort`/`interopHost`.
- `protected wrapSocket(socket): MessageConnection`: `createMessageConnection(new SocketMessageReader(socket), new SocketMessageWriter(socket))`.
- `protected async getRawClass(className, token?): Promise<JavaClass>`: `connection.sendRequest(getClassInfoRequest, { className }, token)` raced against a 10000 ms `setTimeout` that rejects with `InteropTransportError('Java class resolution timeout for ' + className)`.
- `async resolveClassByName(className, token?)` (public). Local primitive, void, array and blank names never reach the wire (#660). A new name goes to `doResolveClassByName`, which creates the 30_000 ms chain timer and then `await this.acquireLock(lockToken)`; a depth-0 call gets a fresh token. The lock is ONE FIFO queue (`lockQueue` and `lockHeld`) and is held across `getRawClass` and `resolveClass`. The catch returns `createStubClass(key, !(cancelled || isInteropTransportFailure(e)))`, so a timeout or refused connection gives an UNCACHED stub carrying `error`.
- `public setConnectionConfig(host: unknown, port: unknown)`: validated; '127.0.0.1' and any integer port from 1 to 65535 are accepted as is. `public clearCache()` disposes the connection and resets the lock and the breaker. `public get connectionGeneration()`. `getResolvedClass(name)`.
- `public async loadImplicitImports()`: sends 8 concurrent `getClassInfos` requests with NO lock (7 implicit packages plus `java.sql`), then `getTopLevelPackages` (a peer that does not support it is handled gracefully).
