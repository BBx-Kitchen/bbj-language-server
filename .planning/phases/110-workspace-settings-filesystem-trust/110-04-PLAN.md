<objective>
Stop the formatter from spawning whatever `java` the OS finds first. A new machine-scoped setting
`bbj.formatter.javaPath` chooses the binary (D-18); a set value is verified and spawned as-is, and an
invalid one cancels formatting with an error (D-19); an empty value makes the formatter walk PATH itself,
verify the first hit and spawn its absolute path (D-20).

Purpose: issue #605 shows the formatter runs a bare `java` from PATH with no check, so a binary placed
earlier on PATH runs on every format-on-save.
Output: `formatter-java-resolver.ts`, the setting, the wired formatter, tests, the user documentation
entry, and the corrected pinned-launcher comment in `no-shell-command-construction.test.ts`.
</objective>
