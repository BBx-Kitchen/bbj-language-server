<objective>
Harden the two file probes the decompile flow uses so they never follow a symlink or read a non-regular
file: `statSize` answers "not a file" for anything but a regular file (D-16), and `isTokenizedFile`
checks with `lstat` before opening, opens with `O_NOFOLLOW | O_NONBLOCK` where available, and re-checks
the handle with `fstat` (D-17).

Purpose: issue #585 shows a symlink or FIFO placed at the probed path makes the extension host read an
unintended file or block on open.
Output: a hardened `decompile-io.ts` with `statSize` exported for direct tests, and new cases in
`test/decompile-io.test.ts`.
</objective>
