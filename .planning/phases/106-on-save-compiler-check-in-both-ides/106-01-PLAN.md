<objective>
Make the language server receive saves and schedule compiler checks by trigger mode. Under
`on-save`, opening or saving a BBj file starts exactly one check with no delay, and typing or an
unrelated rebuild starts none. `debounced` and `off` keep every arming path they have today.

Purpose: the server does not advertise the save capability today, so neither IDE sends
`textDocument/didSave` (research Pitfall 1). Every other on-save behaviour depends on this plan.
Output: a save-capable update handler, reason-aware arming in `BBjDocumentBuilder`, a fake-LSP
test helper that later plans reuse, and `test/on-save-trigger.test.ts`.
</objective>
